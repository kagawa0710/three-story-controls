Camera Helper

Visual tool for authoring camera animations and points of interest.

How to use

Use the + button to record camera positions. Move around, add points, then hit play or use the slider to preview.

Export

Export draft JSON to continue later, or production copy when finished. Works with Story Point, Scroll, and Path Point controls.

WASD or Arrows - Move

U / N - Raise / Lower

Mouse drag - Rotate

Note: Desktop only
