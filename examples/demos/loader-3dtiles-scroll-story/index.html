真鶴・岩の道祖神

真鶴半島にある道祖神の3Dスキャンデータです。 スクロールしてカメラが動く様子をご覧ください。

このデモは @kagawa0710/three-loader-3dtiles (loaders.gl ベース) と @kagawa0710/three-story-controls を組み合わせています。 シンプルなAPIでさっと3D Tilesを表示したい場合に向いています。

Loader3DTiles.load() で { model, runtime } を受け取り、 scene.add(model) するだけで表示できます。 フレーム更新も runtime.update(dt, camera) のみ。
